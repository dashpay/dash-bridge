Dash Bridge widget demo

This page plays the part of a third-party app. It loads the widget SDK (widget.js) and asks the bridge to create a Dash Platform identity, or to sign the user in with one. Only the identity ID (and, for sign-in, a signature) comes back; keys stay in the bridge window. See docs/widget.md.

Sign in with Dash

      

        The user proves they control a Dash Platform identity by signing a
        short message with one of its HIGH or CRITICAL authentication keys,
        inside the bridge. This page gets back the identity ID and the
        signature, never the key.
      

      

        Verify on your server. This demo makes the nonce and
        checks the signature in the browser only to show what happens. A real
        app issues the nonce from its server, and its server runs
        verifyLogin (widget-verify.mjs) against keys it
        fetched from Platform before it starts a session.
